A black maze. A dying flashlight. Something is moving in the dark. Stay close to your partner, listen for it, and run when its eyes appear. If it catches you, the lights go out… then you're back at the entrance.

Solo mode is available now. For online co-op, configure Firebase in this file (instructions below).

VR: either the left or right joystick moves you. Your brother can use the right controller; yours can stay on the left. Desktop: WASD/arrow keys + drag to look. Headphones recommended.

Firebase setup: create a Firebase web app, enable Authentication → Anonymous and Realtime Database, then paste your web config into FIREBASE_CONFIG in this file. For a private test database, rules can allow authenticated users to read/write /rooms/$roomId. Do not use open public rules for a real deployment.
